# Security Policy

## Scope
This repository is public portfolio documentation. It must not contain sensitive operational data.

## Reporting
If you discover sensitive data in this repository, open a private security report through GitHub Security Advisories or contact the maintainer directly.

## Publication Rules
- Use sanitized identifiers and example addressing only.
- Never publish credentials or secrets.
- Keep architecture and process details high-level and defensive.

## Remediation Standard
Sensitive exposure findings are treated as high priority and should be removed immediately, followed by history rewrite if needed.
